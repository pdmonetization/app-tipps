When Gemini Notebook cannot import a source, first separate an import failure from a poor answer. A file that never loads needs a different fix from a document that loads successfully but omits the paragraph you expected.

This researched checklist uses official help checked on October 6, 2026. Diagnostic examples are recommendations, not reproduced error tests. If you need the basic workflow, see our [first notebook guide](/gemini-notebook-mobile-first-notebook/).

## Start with this decision table

| What you see | First check | Sensible next step |
| --- | --- | --- |
| Your file type is missing from the phone's picker | Mobile import options | Try the documented web route for that format |
| PDF loads but a section is absent | Whether the text is readable | Inspect the original and try a short, clearly readable extract |
| Website cannot be added | Access and relevant page content | Use an accessible original page or permitted copied text |
| YouTube link fails | Public access and captions | Check the video's eligibility in Google's source guide |
| Drive source becomes inaccessible | Your current permission | Restore legitimate access or remove the unavailable source |
| Answer ignores an imported document | Selected sources and wording | Select it explicitly and ask a narrower question |

This is an editorial diagnostic sequence. An error message from the app may give a more specific cause, so record it before changing anything.

## Check the format and interface

Google's [desktop source guide](https://support.google.com/gemininotebook/answer/16215270?co=GENIE.Platform%3DDesktop&hl=en) lists documents, audio, images, web pages and public YouTube URLs among supported inputs. The [Android guide](https://support.google.com/gemininotebook/answer/16215270?co=GENIE.Platform%3DAndroid&hl=en) describes a narrower set of mobile app import options. A format supported on the web is not automatically an option in every phone picker.

Try one small source before retrying a batch. A short copied-text note can help distinguish a general app/account problem from a problem with the original file. If the note works, investigate the file rather than repeatedly reinstalling the app.

## Inspect a PDF before converting it

Open the PDF in a normal reader. Can you select the paragraph you need? Does the page contain columns or tables whose meaning depends on layout? A readable-looking scan and a document containing extractable text can behave differently.

As a diagnostic exercise, copy a permitted paragraph into a separate text source and ask the same question. If that works, the original document's extraction or layout deserves attention. This does not prove that all scanned PDFs fail; it gives you a smaller comparison you can inspect.

Do not send confidential documents to an unknown conversion website just to solve an import problem. Prefer an approved local or organizational method when conversion is needed.

## Check websites and videos

Google's source documentation describes text-focused website import and eligibility conditions for YouTube sources. Inspect the exact page rather than assuming a homepage includes the article behind it. A login wall or unavailable page is a different problem from the app overlooking text.

For YouTube, Google specifies public videos with captions and imports their text transcript. Videos uploaded less than 72 hours ago may not yet be importable. Check the captions, link and upload age before retrying. A successful import still does not establish that a visual demonstration was captured.

## Distinguish access loss from stale content

The Android help page says supported Drive sources can sync, and losing access to the original can make a source inaccessible. That is different from a local file you uploaded earlier. Ask whether the source is linked to Drive or is an uploaded copy before assuming that changing the original updated the notebook.

For locally uploaded material, compare the notebook's text with the current original. If you need to replace a source, keep the original until you have checked the replacement. Record which generated summaries may need refreshing afterwards.

## Report a useful error

If the problem persists, note the platform, app version, input type, approximate file size, exact error and whether the short-text test worked. Share only a non-sensitive reproduction with support.
